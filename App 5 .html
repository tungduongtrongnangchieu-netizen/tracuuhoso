⚙️ Tải dữ liệu - Chọn 1 trong 2 cách

📌 Hướng dẫn:
  1. Vào Google Sheet Data2 của bạn
  2. Chọn menu "File → Tải xuống → Microsoft Excel (.xlsx)"
  3. Chọn file Excel vừa tải về
  4. Bấm nút "📤 Tải file Excel"
  5. ✅ Xong! Có thể tìm kiếm ngay
📌 Hướng dẫn Setup (lần đầu, 5 phút):
  1. Vào Google Sheet Data2
  2. Menu "Tiện ích → Editor Apps Script"
  3. Copy code từ Code.gs (link ở dưới) → Paste vào Apps Script
  4. Bấm "Deploy" → "New deployment" → "Web app"
  5. Chọn "Execute as: [Email bạn]" và "Who has access: Anyone"
  6. Bấm "Deploy" → Copy URL Web App
  7. Dán URL vào ô trên → Bấm nút "🔗 Kết nối & Tải dữ liệu"
  8. ✅ Xong! Mỗi lần Sheet thay đổi, chỉ cần refresh trang
